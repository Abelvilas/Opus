Os dados ficam num repositório privado seu. O token fica salvo só neste aparelho (nada é enviado pra outro serviço).

Como criar o token: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Only select repositories = seu repo → Permissions → Contents: Read and write → gere e cole acima.
